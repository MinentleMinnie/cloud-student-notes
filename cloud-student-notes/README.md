# Cloud Student Notes

## Project Overview

Cloud Student Notes is a simple web application that allows students to add and view their study notes in one place.

The project demonstrates how to build a web application using Python and Flask, manage code with Git and GitHub, and prepare an application for deployment to the cloud.

## Features

- Add new study notes.
- View saved notes on the homepage.
- Simple and user-friendly interface.
- Web-based application.

## Technologies Used

- **Python** – Main programming language.
- **Flask** – Python web framework used to build the application.
- **HTML** – Structures the webpage.
- **CSS** – Styles the webpage.
- **Git** – Tracks changes to the project.
- **GitHub** – Stores the project repository.
- **Render** – Planned cloud hosting platform.
- **Gunicorn** – Planned production web server.
